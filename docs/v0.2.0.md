# NetScope v0.2.0 - Advanced Network Engine

## Features

- Platform detection
- Network interface discovery
- IPv4 and IPv6 address representation
- MAC address and MTU representation
- Gateway discovery on supported platforms
- Route Hint support for iSH
- Structured JSON diagnostics
- Capability-based feature reporting

## Platform support

| Platform | Interface discovery | Route Hint |
|---|---|---|
| Linux | Adapter implementation | Platform dependent |
| Windows | PowerShell adapter | Not implemented |
| Termux | Linux adapter | Platform dependent |
| iSH | Restricted by environment | UDP route selection |

## iSH limitations

The iSH environment may reject socket interface enumeration.

Example:

    OSError: [Errno 105] No buffer space available

NetScope reports this as a diagnostic warning.

Route Hint uses a UDP socket to infer the local source
address selected by the operating system. It does not
identify the default gateway.

## Read-only policy

NetScope does not modify network configuration.
It does not change routes, interfaces, DNS settings,
or firewall rules.
